# 📊 AI-Powered Business Analytics & Insights Tool

Bu layihə Excel-də olan satış və maliyyə göstəricilərini avtomatik emal edərək hesablama aparan və Google Gemini API vasitəsilə rəhbərlik üçün strateji biznes insaytı generasiya edən avtomatlaşdırılmış analitika alətidir.

## 🚀 Xüsusiyyətlər
- **Data Emalı:** Pandas və OpenPyXL kitabxanaları ilə Excel faylından gəlir, mənfəət, marja və region üzrə satışların hesablanması.
- **AI İnteqrasiyası:** Generativ AI modeli vasitəsilə biznes nəticələrinin təhlili və avtomatik rəy hazırlanması.
- **Power BI Dashboard:** Əsas KPI-ların və regionlar üzrə performansın vizuallaşdırılması.

## 🛠️ İstifadə Olunan Texnologiyalar
- **Python 3.13** (Pandas, OpenPyXL)
- **Google GenAI SDK** (Gemini API)
- **Power BI** (Interactive Dashboard)
